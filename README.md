## ▌ O que é

Repositório com as **portas lógicas base** que servem de fundação para tudo o que construo no [Digital Logic Sim](https://sebastian.itch.io/digital-logic-sim). Cada arquivo `.json` é um chip salvo no formato do DLS (v2.1.6), pronto para ser importado.

## ▌ Chips disponíveis

| Chip | Arquivo | Função |
|------|---------|--------|
| **NOT** | `NOT.json` | Inversor — saída é o oposto da entrada |
| **AND** | `AND.json` | Saída 1 apenas se **todas** as entradas forem 1 |
| **OR**  | `OR.json`  | Saída 1 se **ao menos uma** entrada for 1 |
| **NOR** | `NOR.json` | OR negado |
| **XOR** | `XOR.json` | Saída 1 se as entradas forem **diferentes** |

## ▌ Como importar

1. Baixe o **[Digital Logic Sim](https://sebastian.itch.io/digital-logic-sim)** (v2.0+).
2. Coloque os arquivos `.json` na pasta de chips do seu projeto DLS.
3. Os chips aparecem na biblioteca, prontos para uso.

## ▌ Projeto completo

Estas portas são os tijolos. O computador inteiro — adders, ULA, registradores e CPUs de 8 a 64 bits — vive no projeto **[UMBRA LIMA ALFA](https://github.com/Lucas-Belucci-Bellini/UMBRA-LIMA-ALFA)**.
